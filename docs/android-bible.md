# Bible.com и ссылки из уроков

## Исследование (16 сентября 2026)

[YouVersion API Usage](https://developers.youversion.com/api-usage) требует регистрации приложения, App Key в X-YVP-App-Key и принятия лицензий для доступных переводов. Для простого открытия сайта API не требуется: [YouVersion прямо разрешает ссылки на стихи](https://help.youversion.com/l/en/article/o8t2xmy9q2-copyright).

Реализованы публичные HTTPS-ссылки `https://www.bible.com/bible/167/{USFM}`. Перевод 167 — [Синодальный](https://www.bible.com/ru/versions/167). Используются [официальные коды книг USFM](https://developers.youversion.com/usfm-reference), включая различие русских 1–4 Царств и английских Samuel/Kings. Нумерация Псалтири не пересчитывается.

Проверено по ответам Bible.com и метаданным страниц:

- `JHN.3.16` → Иоанна 3:16.
- `JHN.3.16-18` → Иоанна 3:16–18.
- `PSA.118.105` → Псалтирь 118:105.
- `MRK.7.1-8.26` сайт интерпретирует как Марка 7:1–8, а диапазон глав `JHN.3-4` вернул 404. Такие диапазоны приложение не передаёт одной ссылкой: показывает выбор начала или конца.

## Реализация

В нижней панели четыре раздела: Курсы, Класс, Библия, Настройки. Библия открывается без входа в учебный аккаунт — это публичный внешний ресурс. Ограничения каталога учебных курсов не меняются.

Экран Библии содержит выбор книги, ввод главы/стихов и открытие сайта. Чтение происходит в обработчике HTTPS-ссылок устройства (браузер или установленное приложение YouVersion). Возврат Android ведёт обратно к уроку. Интернет требуется внешнему сайту; настройка Wi-Fi для синхронизации ответов не ограничивает явно запрошенное открытие браузера.

BibleReferences — независимый от Android слой: 66 книг, русские названия/сокращения, диапазоны, обычный/длинный дефис. Ссылки добавляются к уже отрисованному тексту и вопросам; разметка, номера вопросов и сохранённые ответы не меняются. В ознакомительном режиме ссылки добавляются только в разрешённом вводном тексте. Голая ссылка вида `3:16` распознаётся только при известной книге урока. Цитаты без названия книги и номера главы/стиха нельзя надёжно распознать автоматически: для них нужен явный адрес в исходном уроке. Такие тексты не получают выдуманную ссылку.

Тексты Bible.com не скачиваются в APK и не копируются в базу. Ключа API в приложении нет. Если позже понадобится собственный читатель, отдельный следующий этап: зарегистрировать приложение, выбрать лицензированные переводы, внедрить API и атрибуцию по правилам YouVersion. Это не требуется для текущих ссылок.

## Проверка на Android 10 (0.4.3)

Нативный обработчик регулярных выражений Samsung Android 10 отклонял длинный шаблон имён книг, хотя JVM-тесты проходили. В 0.4.3 распознавание переписано на обычный разбор строк без Regex. На телефоне проверены открытие раздела Библия, переход на Bible.com/bible/167/JHN.3.16 и отображение страницы Иоанна. Проверка выполнялась в новой «Библия · Онлайн» без входа; ссылки внутри авторизованных уроков отдельно на телефоне ещё не проверены.
