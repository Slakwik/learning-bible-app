# Релизная подпись

Для версии 0.4.0 создан отдельный постоянный RSA-4096 ключ с сертификатом сроком 10 000 дней. Сертификат Android самоподписанный — публичный центр сертификации для APK не требуется.

- Публичный сертификат: `android/signing/release-certificate.pem`; его можно распространять.
- Приватное хранилище и файл паролей: `~/.local/share/bible-learning/signing/release.jks` и `release-credentials.json`, вне репозитория, права 0600, родительский каталог 0700. Эти файлы не публиковать; сохранить резервную копию в защищённом хранилище владельца.
- GitHub Secrets: ANDROID_KEYSTORE_BASE64, ANDROID_STORE_PASSWORD, ANDROID_KEY_ALIAS, ANDROID_KEY_PASSWORD.
- GitHub Actions собирает release APK, проверяет подпись через apksigner и совпадение SHA-256 сертификата, запрещает debuggable release. Приватный ключ создаётся один раз и не регенерируется при сборке.

Начиная с 0.4.1 постоянный package ID релизов — `ru.spbchurch.biblelearning.mobile`, название — «Библия · Онлайн». Это позволяет установить актуальное приложение рядом со старыми debug-копиями, не удаляя их черновики. После установки один раз потребуется войти; данные аккаунта/класса загружаются с сайта, локальные черновики старых копий автоматически не переносятся. Будущие релизы с тем же ключом и возрастающим versionCode смогут обновляться с сохранением данных. Старые debug APK имеют другие подписи и не обновляются поверх этим APK. Не удалять старое приложение с черновиками без проверенного переноса. Экспорт пока не является готовой миграцией: импорт остаётся отдельной задачей. Этим релизом установленное приложение пользователя не удаляется и не заменяется.
